## 三、系统架构

### 3.1 数据流

```
GPS定位 (手机端)
  ↓ AMapLocationClient (原生定位SDK)
  ↓ Flutter AmapLocationService (单例)
  ↓
  ├─→ WebSocket /ws/location (实时上报) → Redis实时位置
  ├─→ POST /api/v1/location/report (单点) → PostgreSQL
  └─→ POST /api/v1/location/batch (批量) → PostgreSQL
                                           ↓
  /api/v1/location/track/:userId ← 轨迹查询 ←┘
  /api/v1/fences/auto-check ← 围栏检测
```

### 3.2 离线数据流

```
电池无网络 → 
  OfflineService.cacheLocation() → SharedPreferences
  LocationUploader.enqueue() → 本地文件 (systemTemp)
  ↓ 网络恢复
  OfflineService.syncAll() → POST /api/v1/location/batch
```

### 3.3 隧道/服务器地址管理

```
ServerSelector.init()
  ↓
├─ 1. 本地 SharedPreferences (server_base_url)
├─ 2. GitHub raw: field-tracker-config/config.json
│    (https://raw.githubusercontent.com/gkaikai/field-tracker-config/main/config.json)
└─ 3. 全部不通 → 空字符串 (显示"无法连接")
  ↓ 故障切换
ServerSelector.onRequestFailed() → 尝试备用URL → 重新拉取远程配置
```

| `approvals` | 审批流程 | applicant_id, status |
| `reports` | 工作报告 | (user_id, report_type, report_date) |
